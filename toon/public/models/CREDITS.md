# Model credits

All models in this folder are CC0 1.0 (public domain) by Kenney (https://kenney.nl), each pack's License.txt is kept in its folder.
They are restyled at load time (cel shading + outlines) by toon/src/videos/afterhour/models.ts.
Run `python toon/scripts/merge_models.py` after adding a pack (merges index.<pack>.json and credits.<pack>.md).
