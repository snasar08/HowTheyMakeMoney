# Privacy

This project makes and schedules Shorts for the YouTube channel "How They Make Money".

Its Google sign-in is used by the channel owner only. With that sign-in the project reads the
channel's own YouTube Analytics reports (views and audience retention per video) so the
automated scripts can learn which videos work. It is read-only.

- It does not collect, store or share data about viewers or any other Google user.
- The only data kept is the channel's own per-video statistics, saved in this repository's
  `analytics/` folder.
- The sign-in can be removed at any time at https://myaccount.google.com/permissions.

Questions: open an issue on this repository.
